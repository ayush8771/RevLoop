# Recovery Communication Compliance Policy

Rules the reminder/escalation message agent must cite when drafting any
customer-facing message:

1. **Contact frequency**: no more than 3 total contact attempts per
   customer per outstanding record, minimum 24 hours apart.
2. **Opt-out**: if a customer has opted out, no further contact of any
   kind, permanently, for that customer.
3. **Tone**: messages must be neutral and informative, never threatening
   or guilt-inducing. No urgency language beyond stating the actual due
   date or payment status.
4. **Discount disclosure**: any discount offered must state its exact
   value and expiry, no vague "special offer" language.
5. **Escalation ladder**: escalation to a human/B2B contact only occurs
   after at least one automated attempt has failed, and only for
   invoice_overdue or subscription_lapse cases.

The message agent is instructed to reference the specific rule number it
is complying with when drafting a message, so the audit log can show
*why* a given message is considered compliant.
